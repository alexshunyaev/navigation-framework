\section{Local Planning Implementation: Dynamic Window Approach (DWA)}

\subsection{Introduction}
Following the implementation of the global path planning module using $A^*$, we require a local planner to handle dynamic obstacle avoidance, respect the robot's kinematic constraints, and smoothly navigate towards the waypoints generated by the global planner. Based on the requirements, the \textbf{Dynamic Window Approach (DWA)} was selected for its robustness, mathematical simplicity, and extensibility.

\subsection{Dynamic Window Approach (DWA)}
The Dynamic Window Approach is a local reactive obstacle avoidance and navigation algorithm designed for robots with non-holonomic constraints (e.g., differential drive).

\subsubsection{Kinematic Model}
The robot's state is defined as $(x, y, \theta, v, \omega)$, where $v$ and $\omega$ are the linear and angular velocities. The motion model is updated over a small time step $\Delta t$:
\begin{align}
    x_{t+1} &= x_t + v \cos(\theta) \Delta t \\
    y_{t+1} &= y_t + v \sin(\theta) \Delta t \\
    \theta_{t+1} &= \theta_t + \omega \Delta t
\end{align}

\subsubsection{Dynamic Window}
Instead of evaluating all possible velocities, DWA restricts the search space to velocities that are physically reachable within the next time step, given the maximum accelerations ($a_{max}, \alpha_{max}$). The dynamic window $V_d$ is defined as:
\begin{equation}
    V_d = \{ (v, \omega) \mid v \in [v_c - a_{max}\Delta t, v_c + a_{max}\Delta t], \omega \in [\omega_c - \alpha_{max}\Delta t, \omega_c + \alpha_{max}\Delta t] \}
\end{equation}
This set is further intersected with the absolute limits of the robot's speed to form the final admissible search space.

\subsubsection{Objective Function}
To evaluate the candidate velocities in the dynamic window, the algorithm simulates the robot's trajectory for a short horizon $T$ and scores the predicted trajectory using an objective function. We formulate the cost function to be minimized as:
\begin{equation}
    G(v, \omega) = \alpha \cdot \text{heading\_cost} + \beta \cdot \text{obstacle\_cost} + \gamma \cdot \text{velocity\_cost}
\end{equation}
Where:
\begin{itemize}
    \item \textbf{heading\_cost}: Measures the alignment of the robot with the goal. Smaller angles result in lower costs.
    \item \textbf{obstacle\_cost}: Evaluates the minimum distance from the simulated trajectory to any known obstacle. Trajectories that come within the robot's safety radius are assigned infinite cost. Otherwise, the cost is proportional to the inverse of the minimum distance ($1 / r_{min}$).
    \item \textbf{velocity\_cost}: Penalizes slow movements to encourage the robot to reach the goal quickly.
\end{itemize}

\subsection{Implementation and Integration}
The DWA is implemented in \texttt{src/dwa.py}. The core logic utilizes a \texttt{DWAConfig} dataclass to store the configuration parameters (kinematic limits, resolutions, and weights $\alpha, \beta, \gamma$).

The local planner is integrated with the $A^*$ global planner in \texttt{main.py}. The $A^*$ algorithm provides a list of discrete waypoints. The robot continuously tracks its continuous position $(x, y, \theta)$ and calls \texttt{dwa\_control()} at each control loop iteration to compute the optimal $(v, \omega)$ command to reach the current look-ahead waypoint. Once the robot enters the capture radius of the waypoint, the target is updated to the next point on the global path.

\subsection{Future Extensions}
The DWA's reliance on the objective function $G(v, \omega)$ makes it perfectly suited for the optional extensions detailed in the project requirements. Specifically, the manual weights $\alpha, \beta, \gamma$ can be replaced by a \textbf{Learned Cost Function} (Option A) to implicitly learn optimal navigation behaviors from demonstrations, or explicitly parameterized via \textbf{Multi-Objective Optimization} (Option D) to dynamically trade off safety versus speed.
